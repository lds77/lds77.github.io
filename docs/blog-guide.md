## 1. 표현 규칙 — 지키지 않으면 안 되는 것

- **숫자 실적 문구 금지.** "15년 경력", "○○회 이송", "○○명 이용" 같은 표현을 쓰지 않는다.
  꼭 필요하면 **"오랜"**, **"다수의"** 로 바꿔 쓴다
  → 사이트에 남아 있던 "서비스 경력: 충북지역 10년 이상"(알콜중독 페이지)은 2026-08-05에
  "충북지역에서 오랜 기간" 으로 고쳤다. 앞으로도 사이트에 숫자 실적 문구가 보이면 블로그로 옮기지 말고 고친다.
- 검증되지 않은 실적·수상·순위·후기를 지어내지 않는다
- **고인이송은 제공하는 서비스가 맞다.** 다만 자주 앞세우지 않는다.
  고인이송이 글 주제이거나 꼭 필요한 맥락일 때만 다루고, 다른 서비스 글에는 끼워 넣지 않는다
- 응급 상황을 다루는 업종이므로 **과장·공포 조장 없이 담담하고 신뢰감 있게** 쓴다
- **의료 행위나 치료 효과를 약속하지 않는다.** 이송 서비스이지 의료기관이 아니다
- 요금을 언급할 때는 기본·추가·할증을 함께 적어 나중에 분쟁이 없게 한다
- **"강제입원" 표현은 아껴 쓴다.** 사이트 정신병원·알콜중독 페이지는 검색 유입 목적으로 이 표현을 쓰지만,
  블로그 본문은 **"입원이송", "치료이송"** 을 기본으로 하고, 강제입원은 독자가 그 상황을 찾고 있을 때만
  절차·보호자 역할 설명 안에서 다룬다. 강제성을 부추기는 서술은 하지 않는다
- **보험은 단정하지 않는다.** 사설구급차 이용료는 원칙적으로 건강보험이 적용되지 않는다.
  "실비보험 적용 가능", "의사 소견서가 있으면 적용" 같은 내용은 **"보험사·의료기관에 확인이 필요하다"** 는
  단서와 함께 쓴다. "보험 적용 시 환자부담 대폭 감소" 처럼 결과를 약속하는 문구는 쓰지 않는다

## 3. 글 구조

- 분량 **1,500~2,500자**, 소제목으로 구분
- 흐름: **상황 제시 → 어떻게 진행되는지 → 요금 안내 → 지역·연락 안내**
- 글 끝에 전화번호와 24시간 운영을 다시 안내
- 원고는 `본문 --- CTA --- 태그` 3단 구조로 작성 (발행 패키지 변환용)
- CTA에는 **전화번호와 홈페이지**를 넣는다 (앱스토어 링크 같은 건 없음)
- 태그 15개 내외, **지역명+서비스명 조합**을 넣는다

## 6. 새 이미지가 필요할 때

Claude는 사진풍 이미지를 직접 생성하지 않는다. **Claude가 프롬프트를 써주고 사용자가 생성**한다.
생성한 파일을 `블로그이미지/` 에 넣으면 Claude가 `amb-<서비스>-<장면>.png` 규칙으로 이름을 붙이고
본문 배치와 대체텍스트를 정리한다.

**프롬프트에 반드시 넣을 고정 요소** (기존 이미지와 통일하기 위함)

- 구급차: 흰색 차체, 측면 빨간 가로 스트라이프, 후면 남색+빨강 사선, 하단 노랑·빨강 체커,
  초록 십자, 측면 `EMS AMBULANCE` 로고, 작은 글씨 `WORKS WHENEVER IT WORKS`,
  지붕 앞쪽 빨간 글씨 `응급출동`, 초록 경광등 + 가운데 노란 경광등
- 차량 표기: 측면 창문 위에 `(주)직지응급환자이송단` 과 `010-8841-4114` **두 줄**
- 인물: 감청색 EMS 근무복. **뒷모습·옆모습 위주로, 얼굴이 정면으로 크게 보이지 않게**
- 배경: 한국 도시 풍경(병원·아파트·행사장), 밝은 낮, 맑은 하늘

### 9-3. 요금 — 대조 시점엔 편차가 있었고, 11개 전부 통일함
대조 당시 상태:

- 할증 문구도 갈렸다: 지역 페이지는 "야간 및 공휴일 20%" 로 **주말이 빠져 있었다.**
